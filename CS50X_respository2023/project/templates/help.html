WHY use pocketLibrary.io?

The following is a list of possible uses:

  • Searching by author, to view what books you own by a particular individual
  • Searching by title, when considering buying a new book
  • Searching using partial phrases, when you don't remember a book's full title or author's name
  • Showing friends your collection, in a single place, with options to sort by title or author (A->Z or Z->A)
  • Viewing the total number of books you own, using the 'count books' button

HOW to use pocketLibrary.io?

The following is a description of interactive items:

    HOMEPAGE
  • The title at the top of the page 'pocketLibrary.io', is a button that'll return you to the homepage.
    • LIBRARY
  • ADDING: To add a book, use the "+ BOOK" button in the bottom right. Type in the book's title (required) and optionally the author (if you want to add books quickly, you can leave the author blank and it'll be recorded as by 'Default'.)
  • DELETING: Every book you add to your library is displayed on the bookshelf, in the middle of your screen. Each book has its own 'delete' button, which is a red box with a black 'X'. Books are deleted using their id so if you own multiple copies of a book, with the same title and author, deleting one will leave the others intact.
  • COUNTING: If you would like to see the number of books you own in total, click on the 'COUNT BOOKS' button in the top right.
    • BOOKSHELF
  • SCROLL BAR: All books in your library are displayed on the bookshelf, in the middle of your screen. You can use the white scroll bar, across the shelf, to view all of these books.
  • SORT: You can decide which order the books are displayed, using the sort buttons in the bottom left. (Author or title, A->Z or Z->A.)
    • SEARCH BAR
  • SEARCH: Use the search bar and button to look for (a) book(s), by their title or author. Your search does not need to be the full name so if you're unsure, search for a word/phrase you know and the full book should show in the results. Results show matches for both title and author.
